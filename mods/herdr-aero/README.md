# Herdr Aero

A glassy Aero-style layout for Herdr: `layouts/herdr-aero.json` +
`themes/herdr-aero.json` + this mod. One mod, many roles (`main.js`):
taskbar, desktop, window (pane title bars), menu (Start menu too), dialog,
mines, sol, clippy.

The look:
- Glass: translucent sky-blue frames with a white sheen (GPUI has no
  backdrop blur, so glass is tint over the wallpaper or what's under it).
  Pane frames are 6 px glass, radius 8; panes keep a black terminal.
- Caption buttons: a strip hanging from the top edge, round bottom
  corners, glossy glass, a red close (`icons/aero-*.svg`).
- Caption text: black Segoe UI on a soft white glow.
- Buttons: a gray two-tone gloss; hover sky blue, press deeper blue.
- Taskbar (40 px): dark glass, the Start orb (`icons/aero-orb.svg`), icon
  pins, framed running tabs (brighter = shown, orange pulse = blocked,
  green sweep = working), a two-line clock, and a Show desktop strip
  (minimizes the shown tab).
- Start menu: programs on white (left), places on glass (items with
  `side: true`), a search box that opens the command palette, Shut down
  with an arrow for Log off / Restart (`footer: true` items).
- Menus: light gray, an icon gutter, rounded light-blue hot items.
- Desktop: `img/aurora.png`; boot screen: four pulsing lights on black.
- Fonts: Segoe UI for the UI, Consolas for terminals.

`kit.js` `roundFill()` draws rounded gradients (GPUI clips to rectangles).
Shared state keys are `aero.*`. Mod key commands are `herdr-aero.<command>`
(`start`, `taskman`, `new_tab`, `run`, `shutdown`, ...).

## Windows

Every terminal of the shown space is its own window (`wins.js`, `float.js`):
- normal: a floating glass window over the wallpaper. Drag its title bar to
  move it (it stays where dropped); drag its bottom edge or bottom-right
  corner to resize (an outline follows the pointer, the size applies on
  release). Double-click the title or [] to maximize.
- maximized: the full view next to the desktop icons (the layout's `main`
  block, that pane zoomed if its tab is split). Restore / double-click the
  title floats it again. Only one is maximized at a time.
- minimized: only its taskbar button.

Taskbar buttons are per window: click a minimized one to restore it, the
focused one to minimize it, any other to bring it to the front. Show
desktop (far right) minimizes all; again brings them back. State is
`shared("aero.wins")`: `{ [terminal]: { state, w, h } }`. Floating windows
sit above the maximized one (they're overlays). A split tab shows each pane
as its own window.

## Art

All icons are vector art in a glossy Frutiger Aero style (glass and orbs,
aqua / sky blue / fresh green, white top gloss, soft shadows), generated by
`art/aero_icons.py` (`python art/aero_icons.py` rewrites `icons/`). Each icon
is written as `<name>.svg`, `<name>-sm.svg` and, for badges, `<name>-xs.svg`.
Hand-drawn: `icons/aero-*.svg` (caption glyphs, orb, user tile, grip, search),
`icons/check.svg`, `arrow-*.svg`, `radio-*.svg`, `img/monitor.svg`,
`img/sol-back-*.svg` (bubbles, leaf). Wallpapers: `img/aurora.png`,
`img/bubbles.png`. The classic bevels are soft rounded boxes (`kit.js` `bevel`).
